Пошаговая инструкция для привязки существующего локального проекта к GitHub:

Шаг 1. Создать репозиторий на GitHubЗайдите на сайт github.com.Вверху нажмите на кнопку «New» (или значок + → «New repository»).Введите Repository name (название проекта).Обязательно: не ставьте галочки напротив «Add a README file», «Add .gitignore» и «Choose a license» — репозиторий должен быть абсолютно пустым.Нажмите зелёную кнопку «Create repository».Скопируйте полученную ссылку на репозиторий.

Шаг 2. Подготовить файл .gitignore 
В корневой папке проекта создайте файл с точным именем .gitignore (если его ещё нет) и добавьте туда папки, которые не должны улетать в Git:   
node_modules/
dist/
build/
.env

Шаг 3. Команды в терминале
Откройте терминал в корневой папке проекта в VS Code (Ctrl + ~ или выберите меню Терминал → Создать терминал) и выполните команды по порядку:   
Инициализация репозитория: 
git init

Настройка автора (выполняется 1 раз на компьютере):
git config --global user.name "Ваше Имя или Ник"
git config --global user.email "ваша_почта@example.com"

Добавление всех файлов в индекс:
git add .
Создание первого коммита:
git commit -m "Initial commit"
Переименование основной ветки в main:
git branch -M main
Привязка удалённого репозитория:
git remote add origin https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git    (пример https://github.com/IhorSafronov/relay-pet.git)
(замените адрес на ссылку, скопированную на Шаге 1) Первая отправка проекта на GitHub:
git push -u origin main
(если выскочит окно браузера, подтвердите авторизацию, нажав «Sign in with your browser»)   

Как работать дальше в процессе разработки После того как проект один раз привязан, для сохранения любых последующих правок и отправки их на GitHub используются всего три команды:
git add . — подготовить все изменения к коммиту.
git commit -m "Краткое описание того, что сделали" — зафиксировать изменения.
git push — отправить изменения в репозиторий на GitHub.
